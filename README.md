# Bank OOP Project

## Project Description
A banking system developed using Object-Oriented Programming (OOP) concepts in C#.

The project demonstrates core OOP principles including:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Delegates & Events
- Static Classes

---

## System Features
- Client Management
- User Management
- Login System
- Money Transfer
- Account Types
- Validation System
- Login History
- Transfer Logging

---

## Technologies Used
- C#
- .NET
- Console Application
- Git & GitHub
- Text File Storage
